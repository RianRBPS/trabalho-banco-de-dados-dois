# Orientações para agentes

- Este repositório contém o trabalho em grupo de Banco de Dados II, em português.
- Use `docs/originais/trabalho-pratico.docx` e os diagramas como referência candidata; confirme a versão com o grupo quando necessário.
- Preserve os originais. Registre interpretações em `docs/decisoes.md`; não invente requisitos ausentes.
- SQL deve ser compatível com PostgreSQL. Mantenha nomes do modelo, PKs, FKs e regras de integridade.
- Valide schema, carga e três consultas em banco isolado. Nunca apague bancos existentes sem autorização.
- Use somente dados fictícios nos exemplos. Não versione credenciais, dumps reais ou dados pessoais.
- As três consultas precisam combinar várias tabelas e responder perguntas úteis ao streaming.
- Não considere a menção verbal a pastas de ferramentas como configuração confirmada. Não crie `.claude` ou `.agents` sem esclarecer a intenção.
